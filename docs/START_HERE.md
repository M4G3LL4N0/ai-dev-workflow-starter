# Start Here

This repository is a starter kit for AI-assisted software development.

## What this repo contains
- AI rules
- architecture guidance
- engineering standards
- Supabase guidance
- GitHub issue templates
- pull request template
- CI workflow
- utility scripts

## How to use this repo
1. Create a branch for each task
2. Ask an AI tool to inspect the repo before making changes
3. Keep changes small and reviewable
4. Run verification scripts
5. Open a pull request instead of changing main directly

## Recommended AI workflow
1. Open the repo in Cursor
2. Use Aider for file-based edits
3. Use GitHub branches for every change
4. Run:
   - ./scripts/verify-repo.sh
   - make verify
5. Commit and push
6. Open a pull request

## Goal
Use this repo as a reusable system you can copy into future projects.
