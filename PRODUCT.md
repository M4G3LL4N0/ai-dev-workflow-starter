# Product Context

## Product purpose
This repository is a starter system for AI-assisted software development workflows.

## Product expectations
- Clear task definitions
- Safe development practices
- Reviewable pull requests
- Repeatable workflows
- Strong consistency across AI tools

## Operating philosophy
- Build incrementally
- Ship reviewable improvements quickly
- Avoid speculative complexity
- Prefer durable systems over hacks

## Non-goals
- No unsafe production shortcuts
- No ambiguous AI instructions
- No hidden changes outside review
